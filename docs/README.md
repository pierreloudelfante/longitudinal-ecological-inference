# Index de la documentation

## Document principal

Le document principal est :

1. `PREMIERS_RESULTATS_KRT_NLS_PANEL_3000.md` — présentation concise de l'échantillon, des six modèles KRT H0A/H1, des douze NLS H0A/H1/H2/H4, des premiers résultats sur 1962, 1986 et 2022 et des diagnostics essentiels ;
2. la version PDF autonome du même document est placée dans `output/pdf/` ;
3. le ZIP compact correspondant est placé dans `deliverables/`.

Les six KRT et les douze NLS présentés reposent sur le même panel V2 de 3 000 communes. Une seule anomalie inter-dénominateurs apparaît parmi les 9 000 couples commune-année : `02643` en 1986, avec 392 suffrages exprimés pour 383 inscrits. Le panel reste équilibré et un panel V3 soumis à une validation plus stricte est préparé pour les prochains calculs.
